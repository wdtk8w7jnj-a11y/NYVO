# NYVO — instructions de reprise pour Claude Code

## Point d'entrée
1. Lire `handoff/premium-editorial/README.md` et `handoff/premium-editorial/PROMPT_CLAUDE.md`.
2. Pour les anecdotes, lire `handoff/premium-editorial/stories/README.md`, puis le README de l'histoire active.
3. Vérifier la branche, les modifications non intégrées et l'état réel du site avant d'agir. Les sources Sites les plus récentes priment sur un ancien snapshot.

## Règles
- Préserver l'accès propriétaire privé du site. Le dépôt GitHub est public : aucun secret, jeton, donnée privée, capture de configuration ou contenu authentifié.
- Ne pas déployer, modifier les contrôles d'accès, fusionner dans `main` ou réécrire l'historique sans demande explicite.
- Marquer clairement chaque étape : brouillon, validé, intégré, publié. Ne jamais confondre ces statuts.
- Vérifier les faits avec les sources enregistrées. Distinguer le récit factuel de l'analyse NYVO.
- Signaler comme illustratives les positions tactiques non issues du tracking.
- Conserver articles, sources, infographies, favoris, anti-spoilers et préférences. Respecter l'assemblage et les tests indiqués dans le handoff.
- Inspecter les travaux en cours avant édition; ne jamais les écraser.
