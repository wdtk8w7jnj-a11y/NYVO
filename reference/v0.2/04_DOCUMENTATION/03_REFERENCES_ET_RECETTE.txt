RECETTE CIBLE
- Première ouverture propre, pays et favoris facultatifs, Plus tard sans compte. Retour réglages sans perte de choix.
- Changer pays conserve les favoris mais modifie contexte diffusion ; jamais inventer de chaîne.
- Choisir date puis filtre sans retour silencieux au jour de démo ; état vide utile.
- Ouvrir chaque rencontre, retour liste stable ; scores/horaires et diffusion cohérents entre accueil, liste, fiche, favoris.
- Enregistrer/retirer match/article/vidéo ; suivre/ne plus suivre équipe/compétition ; relancer navigateur et vérifier.
- Tous les onglets de fiche fonctionnent, données absentes explicites, pas zéro inventé.
- Non confirmé : aucun CTA vers fausse chaîne ; interrompu : dernier état daté + reprise ; limité : manque annoncé.
- Sans spoilers : pas de score, événements, stats/classement révélateurs ni contenu associé dans texte, attribut accessible ou miniature ; chaîne/horaire disponibles ; révélation explicite sans compte.
- Aucun autoplay vidéo ; aucun faux abonnement/paiement ; démo clairement identifiée.
- Navigation clavier, libellés, contrastes, cibles tactiles, focus et dialogues ; absence débordement horizontal sur smartphone.
- Les tests automatisés de logique ne suffisent pas pour déclarer l'expérience mobile validée.
